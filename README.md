# 🤖 AI Healthcare Chatbot

An intelligent AI-powered healthcare chatbot designed to assist users with preliminary health consultations, symptom checking, and medical information.

---

## 📌 Project Overview
This project provides a user-friendly interface where users can chat with an AI model to get quick health-related guidance and suggestions.

---

## 🛠️ Tech Stack
- **Backend:** Python (`app.py`), Flask / FastAPI
- **Frontend:** HTML5 (`index.html`), CSS3 (`style.css`)
- **Dependencies:** Listed in `requirements.txt`
